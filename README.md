# Mitmproxy定位伪造工具 (Go版本)

## 功能特性
- 基于Go语言开发的定位伪造工具
- 自动管理Windows系统代理设置
- 内嵌mitmproxy CA证书
- 单实例控制，重复启动直接打开微信小程序
- 启动时自动检测并清理异常代理设置
- 完善的退出处理机制

## 文件说明
- `Mitmproxy定位伪造工具.exe` - 主程序可执行文件
- `*.go` - Go源代码文件
- `app.ico` - 程序图标文件
- `build_with_icon.bat` - 带图标编译脚本
- `uninstall.go` - 证书和计划任务卸载功能

## 编译要求
- Go 1.16+
- Windows系统
- rsrc工具（用于嵌入图标）

## 使用方法
1. 双击运行 `Mitmproxy定位伪造工具.exe`
2. 首次运行需要管理员权限
3. exe运行时重复双击会直接打开微信小程序
4. 关闭窗口即可停止服务并清理代理设置
